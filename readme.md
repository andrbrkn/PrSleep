**Проект оценки изменения времени засыпания после использования приложения для медитации**

Учебный проект оценки эффективности приложения для медитации для уменьшения времени засыпания на искусственно сгенерированных данных

**Устновка**

выполнить команду в командной строке pip install -r requirements.txt для установки необходимых библиотек и зависимостей
предполагается, jupyter notebook установлен заранее

**Запуск**

Открыть в jupyter notebook файл project_sleep.ipynb, выполнить пункт меню *Run - Run All Cells*
